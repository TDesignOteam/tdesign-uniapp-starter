# TDesign UniApp 组件库示例

本项目使用 CLI 模式。从 uniapp 官方[脚手架工程](https://uniapp.dcloud.net.cn/quickstart-cli.html#%E5%88%9B%E5%BB%BAuni-app)微微改造而来。支持：

- [x] 自动导入
- [x] 类型提示
- [x] less 预处理器

不同类型：

- 主分支（`develop`）为完整模板（进行中）
- [template](https://github.com/novlan1/tdesign-uniapp-demo-cli/tree/template) 分支为极简模板，适用于新项目启动、复现问题等
